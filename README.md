# TV Cleaner

Безопасная очистка телевизора **Digma Pro 55L (Google TV)** от рекламных
и «следящих» приложений через ADB.

## Вариант А: Готовое решение (CleanYourTV)

**Перед запуском нашего скрипта проверьте официальный репозиторий CleanYourTV
на GitHub:** <https://github.com/Gathin23/cleanyourtv> — у него есть README на
многих языках (для нас ближе всего `README.uk.md`).

- Готовые списки пакетов лежат в папке
  [`examples/`](https://github.com/Gathin23/cleanyourtv/tree/main/examples):
  **одна папка на модель** с именем вида `brand-model` (например
  `hisense-65d62qh/`), внутри — файл `debloat.txt` со списком пакетов, которые
  безопасно отключить именно на этой прошивке.
- Списки применяют скрипты самого проекта (`disable.sh`; откат — `restore.sh`).
  Обратите внимание: их списки — «отправная точка», в их README прямо сказано
  «закомментируйте то, что вам нужно».
- **Если для вашей модели (Digma Pro 55L) готовый файл там есть — можно
  использовать его напрямую** по инструкции из их README.
- Проверено 13.11.2026: папки для Digma в `examples/` нет — ни один путь в
  дереве репозитория не содержит «digma». Значит, для Digma Pro 55L готового
  списка сейчас нет и нужно переходить к Варианту Б (наш скрипт). Репозиторий
  активно пополняется, поэтому заглянуть туда стоит ещё раз перед запуском.
- Уточнить, под каким именем искать свою модель, можно у самого телевизора:
  `adb shell getprop ro.product.model` (Digma выпускает телевизоры под
  ODM-платформами, поэтому список может найтись под именем платформы, а не бренда).

**Если готового списка нет — переходите к нашему скрипту (Вариант Б ниже):**
пункт 3 «Аудит» подберёт подозрительные пакеты именно на вашем телевизоре.

## Вариант Б: наш скрипт TV Cleaner

> ⚠️ **Все действия вы выполняете на свой страх и риск.** Программа не удаляет
> пакеты: она только **отключает** их командой `pm disable-user` (это обратимо),
> а пункт 5 меню возвращает всё обратно. Но любое вмешательство в систему
> телевизора может привести к странному поведению интерфейса, поэтому
> сначала сделайте пункт 3 (аудит) и читайте список внимательно.

## Что делает программа

| Пункт меню | Действие |
| --- | --- |
| 0 | Инструкция по проверке CleanYourTV (готовый список под вашу модель) |
| 1 | Подключиться к телевизору (`adb connect IP:5555`) |
| 2 | Показать все пакеты (защищённые помечены `[защищён]`) |
| 3 | Аудит: показать подозрительные пакеты, **ничего не меняя** |
| 4 | Отключить подозрительные пакеты (с подтверждением `y/n`) |
| 5 | Восстановить: включить пакеты, отключённые программой (по журналу) |
| 6 | Отметить приложения «галочками» — выбрать, что отключить, вручную |
| 7 | Выход |

Пункт 6 удобен, когда нужно отключить не только «рекламные» по имени пакеты:
список показывается страницами по 20 строк, пакет отмечается номером,
`a` — применить, `q` — отмена. Критичные пакеты (из `CRITICAL` в `config.py`)
отметить нельзя — программа не даст их выключить.

Подозрительными считаются пакеты, в имени которых есть слова из
`SUSPICIOUS_KEYWORDS` (`ads`, `analytics`, `tracking`, `recommend`, `telemetry`,
`adservice`, `monitor`, `stats`, `metrics`) — кроме тех, что попали в белый
список `WHITELIST`. **Белый список имеет приоритет:** пакет из `WHITELIST`
никогда не будет отключён, даже если в имени есть «рекламное» слово
(например, `com.digma.ads` не тронет).

Всё, что программа сделала, записывается в `cleaner_log.txt`, а список пакетов
до изменений сохраняется в `backup_packages.txt` (оба файла не выкладываются в git).

## Шаг 1. Подготовка ADB на компьютере

1. Скачайте **platform-tools** (внутри `adb.exe`): https://developer.android.com/tools/releases/platform-tools
2. Распакуйте, например, в `C:\platform-tools`.
3. Либо добавьте эту папку в `PATH`, либо пропишите полный путь в `config.py`:

```python
ADB_PATH = r"C:\platform-tools\adb.exe"
```

Проверка: откройте терминал и выполните `adb version` — должна появиться версия.

## Шаг 2. Включить отладку по сети на Digma Pro 55L

1. Включите телевизор и подключите его к той же сети Wi-Fi, что и компьютер.
2. **Узнайте IP-адрес телевизора:** Настройки → Сеть и Интернет → Сеть →
   выберите вашу сеть → IP-адрес (например, `192.168.1.21`).
3. **Включите режим разработчика:** Настройки → Система → О телевизоре →
   нажмите 7 раз подряд на пункт «Сборка» («Номер сборки»), пока не появится
   сообщение «Вы стали разработчиком».
4. Откройте Настройки → Система → **Для разработчиков** и включите
   **Отладка по ADB** (в некоторых прошивках пункт называется
   «Отладка по USB» / «ADB debugging»).
   *Если пункт не включается (серый):* подключите в USB-порт телевизора
   любую USB-клавиатуру или флешку — на части прошивок Google TV пункт
   становится активным только при подключённом USB-устройстве.
5. Впишите IP телевизора в `config.py`:

```python
TV_IP = "192.168.1.21"
```

## Шаг 3. Установка и запуск

```bat
cd D:\TV_Cleaner
python -m pip install -r requirements.txt
python main.py
```

Дальше по меню: `1` (подключиться) → `3` (аудит) → `4` (отключить, подтвердив `y`).

## Как откатить изменения

Пункт `5` читает `cleaner_log.txt`, находит пакеты, отключённые программой, и
включает их обратно. Если что-то пошло не так, а журнал потерян — можно
включить пакет вручную:

```bat
adb connect 192.168.1.21:5555
adb shell pm enable com.example.package
```

Посмотреть, что сейчас отключено:

```bat
adb shell pm list packages -d
```

## Если что-то не работает

| Сообщение | Что проверить |
| --- | --- |
| `Ошибка: Устройство не найдено` | IP в `config.py`, что телевизор включён, что он в той же сети, что «Отладка по ADB» разрешена |
| `ADB не найден` | Путь `ADB_PATH` в `config.py` или `adb` в `PATH` |
| `не в состоянии «device»` | На телевизоре при подключении может появиться запрос «Разрешить отладку» — подтвердите его пультом |
| `не allowed to disable` / ошибка на конкретном пакете | Системный пакет запрещено отключать — это нормально, программа пропустит его и напишет в журнал |

## Структура проекта

```
TV_Cleaner/
├── main.py           # CLI-меню (colorama)
├── config.py         # IP, путь к ADB, WHITELIST, SUSPICIOUS_KEYWORDS
├── adb_manager.py    # вызовы adb: connect, get_packages, disable/enable
├── analyzer.py       # поиск подозрительных пакетов (белый список в приоритете)
├── cleaner.py        # резервная копия, отключение, восстановление, журнал
├── checklist.py      # выбор приложений «галочками» (пункт 6)
├── requirements.txt
└── README.md
```

Программа **не содержит** команд `pm uninstall`, `pm uninstall --user`,
`rm -rf` и подобных — удаления пакетов и файлов нет.
